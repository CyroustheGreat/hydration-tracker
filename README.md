# Hydration Tracker

Track your water intake during the day.

## Features

- Big progress ring showing today's intake vs your daily goal (2,000 ml by default)
- One-tap logging: + Glass (250 ml), + Bottle (500 ml), or quick amounts (+100 / +200 / +330 / +500 ml)
- Custom amount, and drink types: Water, Sparkling, Tea, Coffee, Juice, Other
- Today's log with time for every drink, plus edit by deleting an entry, and clear-the-day
- Last 7 days chart, 7-day average, days at goal, and best day
- Settings: daily goal, glass size, bottle size, and ml / oz units
- Data is saved in your browser (localStorage) — a new day starts fresh at midnight

## Run it

Open https://CyroustheGreat.github.io/hydration-tracker/ once GitHub Pages is enabled for this repo (Settings → Pages → Deploy from a branch → main / root).

Or open `index.html` directly in any browser — no build step, no server needed.
